# PokerNode 德州扑克规则基线

PokerNode 当前实现的是 2–6 人、固定盲注、无上限德州扑克现金桌。Go 服务端是牌局状态的唯一权威，客户端只能提交动作，不能决定发牌、合法操作或结算结果。

## 发牌与随机性

- 每手使用标准 52 张牌，无大小王。
- 使用 Go `crypto/rand` 作为操作系统级加密安全随机源。
- 使用 Fisher–Yates 洗牌；每一步通过拒绝采样取得均匀随机下标，不使用 `math/rand` 发牌。
- 每位玩家发两张底牌；翻牌、转牌、河牌前各烧一张牌。
- 未摊牌时只向玩家发送自己的底牌；摊牌时展示仍在争夺底池的玩家底牌。

这属于“服务端加密安全随机”，不是玩家可独立验证的 provably fair。服务器仍然是可信方；如果未来面向陌生用户运营，应增加多方种子承诺/揭示、牌堆承诺和不可篡改手牌历史。

## 位置与行动顺序

- 按钮每手顺时针移动到下一位有筹码的玩家。
- 三人及以上：按钮左侧依次为小盲和大盲，翻牌前由大盲左侧第一位行动。
- 单挑：按钮同时是小盲，按钮翻牌前先行动；大盲在翻牌后各轮先行动。
- 大盲在无人加注时保留过牌选项。

## 下注与全下

- 支持弃牌、过牌、跟注、下注、加注和全下。
- 最小首次下注为大盲；最小加注增量等于本轮最后一次完整下注或加注的增量。
- 不足一个完整加注的短码全下不会为已经行动的玩家重新开放加注。
- 多个短码全下的累计增量达到一个完整加注时，只为实际面对完整增量的玩家重新开放加注。
- 无上限桌不限制完整加注次数，最大下注为玩家当前全部筹码。

## 摊牌与底池

- 使用两张底牌与五张公共牌中的任意组合，取最佳五张牌。
- 支持高牌、一对、两对、三条、顺子、同花、葫芦、四条、同花顺和完整踢脚比较。
- 按每位玩家的实际投入分层计算主池和多个边池；弃牌玩家的投入留在底池，但没有获奖资格。
- 平局按每个底池分别均分；无法均分的最小单位筹码，从按钮左侧第一位获胜玩家开始分配。
- 所有筹码流转使用整数美分，不使用浮点数。

## 规则与实现参考

- [Poker TDA 2024 Rules](https://www.pokertda.com/view-poker-tda-rules/)：边池、奇数筹码、最小加注和短码全下重开规则。
- [PokerStars Texas Hold'em Rules](https://www.pokerstars.com/poker/learn/lesson/texas-holdem-rules/)：行动顺序、盲注、四轮下注与最佳五张牌。
- [yuga-labs/poker-engine](https://github.com/yuga-labs/poker-engine)：状态机、合法动作和复杂边池测试的结构参考。
- [chehsunliu/poker](https://github.com/chehsunliu/poker)：MIT 许可的 Go 牌型评估器，用作测试阶段的独立差分基准。

## 自动验证

- 牌型评估与参考库进行 5,000 组随机七张牌差分比较。
- 1,000 手牌的随机六人动作模拟验证每手必定结束且总筹码严格守恒。
- 独立测试覆盖单挑盲注/顺序、烧牌、短码全下重开、累计短码重开、主池/边池、奇数筹码和状态持久化。
- API 集成测试使用本地模拟 New API，验证买入、开局、行动、离桌与最终余额守恒，不触碰真实 New API 余额。

## 上线前仍需完成

- 不可篡改的逐手行动日志、完整手牌历史和确定性回放。
- 玩家可验证的多方随机协议，而非只信任服务器随机源。
- 行动计时、断线超时自动过牌/弃牌、坐下等待大盲等现金桌运营规则。
- New API 余额调整的上游幂等键、对账任务与双重记账审计。
- 更高规模的属性测试、并发测试、故障注入和外部安全审计。
